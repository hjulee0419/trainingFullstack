# TodoList 프론트엔드 스타일 가이드

버전: 1.0 / 작성일: 2026-07-30

참조: `4-project-structure.md`(8장 프론트엔드 디렉토리 구조, `styles/globals.css`), `8-wireframe.md`(S1~S7 화면 구조)

## 1. 문서 개요

### 1.1 목적
사용자가 제공한 캘린더형 일정관리 서비스 스크린샷의 시각 언어(정보 밀도, 색상 사용 규칙, 내비게이션/컴포넌트 패턴)를 참고해, TodoList 프론트엔드(FE-1~FE-10, 아직 미착수) 구현 시 사용할 디자인 토큰과 컴포넌트 스타일 규칙을 정의한다. 특정 서비스의 브랜드(로고·서비스명)를 그대로 재현하는 것이 목적이 아니라, 그 UI가 채택한 **일반적인 생산성 도구 디자인 패턴**(고밀도 리스트, 명확한 상태색 구분, 미니멀 아이콘, 사이드 내비게이션)을 TodoList 도메인(할일/카테고리/상태)에 맞게 재해석한다.

### 1.2 참고 스크린샷에서 추출한 패턴
- **좌측 내비게이션 + 상단 툴바** 조합의 2단 레이아웃(주요 액션 버튼 → 미니 요약 위젯 → 체크박스형 필터 목록 → 보조 메뉴 순으로 세로 배치).
- **원색 채움 버튼(주요 액션) vs 아웃라인 버튼(보조 액션)**의 뚜렷한 구분.
- **세그먼트 탭**(일간/주간/월간/목록 형태)으로 뷰 전환, 활성 탭만 배경색 채움.
- **체크박스 색상으로 카테고리 구분**(항목마다 각기 다른 강조색의 정사각 체크박스).
- **요일별 의미색**(일요일=빨강, 토요일=파랑) — 날짜/기한 관련 정보에 색으로 의미를 부여하는 규칙.
- **옅은 회색 배경 위 흰색 카드/그리드**로 콘텐츠 영역을 구획, 테두리는 얇은 회색 선.
- 우측 상단에 **작은 안내 배너 텍스트**(공지/도움말성 문구)를 본문보다 옅은 색으로 배치.
- 하단 고정된 **요약 카운터**("오늘 할 일 N건" 형태의 접이식 위젯).

### 1.3 적용 범위와 한계
- 본 문서는 **디자인 토큰(색상/타이포그래피/간격)과 컴포넌트 스타일 규칙**을 정의하며, 화면별 레이아웃 구조는 `8-wireframe.md`(S1~S7)를 그대로 따른다 — 이 문서가 와이어프레임의 구조를 변경하지 않는다.
- 접근성(A11y)은 `2-PRD.md` 6.5에서 범위 외로 명시되어 있으므로, 본 문서도 WCAG 대비비 등 엄격한 접근성 기준까지는 다루지 않는다(다만 포커스 아웃라인 등 브라우저 기본 동작은 임의로 제거하지 않는다).
- 참고 스크린샷의 좌측 상시 사이드바(미니 캘린더, 구독 캘린더 등)는 TodoList의 실제 화면 구조(GNB 가로 메뉴, `8-wireframe.md` 참조)와 다르므로 레이아웃 자체를 그대로 이식하지 않고, 색상·버튼·체크박스·탭 등 **컴포넌트 단위 패턴만** 채택한다.

## 2. 디자인 원칙

1. **정보 밀도 우선**: 여백을 과하게 주지 않고 목록/카드 안에 상태·날짜·카테고리 정보를 촘촘히 배치한다(참고 스크린샷의 캘린더 그리드처럼 한 화면에서 많은 항목을 훑어볼 수 있어야 함).
2. **상태는 색으로 즉시 구분**: 할일 상태(시작 전/진행중/완료/기한초과) 4가지는 텍스트뿐 아니라 색상 뱃지로도 항상 함께 표시한다.
3. **주요 액션은 하나만 강조**: 화면마다 원색 채움 버튼(Primary)은 핵심 액션(새 할일, 저장, 로그인) 하나에만 쓰고, 나머지는 아웃라인/텍스트 버튼으로 낮춘다.
4. **의미 있는 색만 사용**: 장식적 컬러 사용을 지양하고, 색은 항상 상태·요일·필수여부 같은 의미를 전달할 때만 사용한다.
5. **반응형은 축소이지 재설계가 아님**: 모바일에서는 가로 배치 요소가 세로로 쌓이고 GNB가 햄버거로 축소될 뿐, 정보 구성과 흐름은 데스크톱과 동일하게 유지한다(`8-wireframe.md` 각 화면의 모바일 절 원칙과 동일).

## 5. 레이아웃 & 간격

- **간격 스케일**(4px 기준): `--space-1: 4px`, `--space-2: 8px`, `--space-3: 12px`, `--space-4: 16px`, `--space-6: 24px`, `--space-8: 32px`.
- **모서리 반경**: 입력창/버튼 `--radius-sm: 6px`, 카드/다이얼로그 `--radius-md: 10px`, 상태 배지/필터 탭 `--radius-pill: 999px`.
- **그림자**: 카드 `--shadow-card: 0 1px 2px rgba(31,33,38,0.06)`, 다이얼로그 `--shadow-modal: 0 8px 24px rgba(31,33,38,0.16)` — 참고 스크린샷처럼 그림자보다 **얇은 회색 테두리(`--color-gray-300`)**를 기본 구획 수단으로 우선한다.
- **GNB 높이**: 데스크톱 56px 고정.
- **브레이크포인트**(`4-project-structure.md`/`8-wireframe.md`와 일치): 모바일 `< 768px`, 태블릿 `768px ~ 1024px`, 데스크톱 `> 1024px`.

## 6. 컴포넌트 스타일

### 6.1 버튼
- **Primary**(배경 `--color-primary`, 텍스트 흰색, hover 시 `--color-primary-hover`): 화면당 핵심 액션 1개(로그인, 가입하기, 저장, + 새 할일)에만 사용.
- **Secondary/Outline**(배경 흰색, 테두리 `--color-gray-300`, 텍스트 `--color-gray-900`): 취소, 목록으로, 정보 수정 등 보조 액션.
- **Danger**(배경 흰색 또는 `--color-danger-bg`, 텍스트/테두리 `--color-danger`): 삭제 버튼 전용, 항상 컨펌 다이얼로그(`ConfirmDialog`)와 함께 사용(`8-wireframe.md` S4/S5 삭제 컨펌 참조).
- 높이 36px(콤팩트), 좌우 패딩 `--space-4`, `--radius-sm`.

### 6.2 입력창 & 검색창
- 배경 흰색, 테두리 `--color-gray-300`, 포커스 시 테두리 `--color-primary` + 옅은 외곽선.
- 높이 36px, `--radius-sm`, 좌측 아이콘이 필요한 경우(검색 등) 아이콘 20px, 좌측 패딩으로 텍스트와 분리.
- 유효성 오류 시 테두리를 `--color-danger`로 바꾸고 필드 하단에 `--font-caption` 크기의 오류 문구를 `--color-danger`로 표시(로그인 E-8, 할일 등록 E-1 등).

### 6.3 상태 배지 (`TodoStatusBadge`)
- `--radius-pill`, 좌우 패딩 `--space-2`, `--font-caption` + 굵기 500.
- 색상은 3.3절 표를 그대로 사용. 아이콘 없이 텍스트만("시작 전"/"진행중"/"완료"/"기한초과")으로 충분히 구분되도록 배경색 대비를 우선한다.

### 6.4 필터 탭 / 세그먼트 컨트롤
- 참고 스크린샷의 일간/주간/월간 탭 패턴을 카테고리·상태 필터 프리셋이나 목록 정렬 옵션(FR-13, Could)에 적용할 수 있다.
- 비활성 탭: 배경 없음, 텍스트 `--color-gray-700`. 활성 탭: 배경 `--color-primary`, 텍스트 흰색, `--radius-pill`.

### 6.5 체크박스
- 16x16px, 미체크 시 테두리 `--color-gray-300`, 체크 시 배경 `--color-primary`(카테고리 필터 등 단일 의미일 때) — 참고 스크린샷처럼 카테고리마다 다른 강조색을 쓰고 싶다면 카테고리 생성 시 색상 토큰 팔레트(`--color-primary`, `--color-status-completed-text`, `--color-saturday` 등 기존 의미색 중에서만 선택)를 재사용하고 임의 색을 무한 추가하지 않는다.

### 6.6 GNB / 내비게이션
- 데스크톱: 가로 배치, 좌측 서비스명 + 메뉴(할일 목록/카테고리/계정), 우측 사용자 드롭다운(`8-wireframe.md` 10장).
- 활성 메뉴 항목: 텍스트 `--color-primary` + 하단 2px 밑줄, 배경은 채우지 않음(참고 스크린샷의 "전체 일정 보기" 같은 배경 채움 방식 대신, GNB 가로 메뉴에는 밑줄 방식이 더 적합).
- 모바일: 햄버거(☰) 토글, 펼쳤을 때 메뉴 항목은 세로 리스트로 `--color-gray-100` hover 배경.

### 6.7 리스트 아이템 (`TodoListItem`, 카테고리 행)
- 카드형, 배경 흰색, 테두리 `--color-gray-300`(카드 사이 구분은 그림자 대신 1px 구분선), 내부 패딩 `--space-4`.
- 좌측에 `TodoStatusBadge`, 우측 정렬로 카테고리 라벨(`--font-caption`, `--color-gray-500`), 하단에 날짜 범위(`--font-caption`), 완료 시 완료일시 추가 표시(FR-11).
- hover 시 배경 `--color-gray-50`로 전환해 클릭 가능함을 암시(참고 스크린샷의 그리드 셀 hover와 동일한 의도).

### 6.8 다이얼로그 (`ConfirmDialog`)
- 화면 중앙, `--radius-md`, `--shadow-modal`, 배경 흰색, 딤 처리된 배경(반투명 검정 `rgba(31,33,38,0.4)`).
- 제목 없이 본문 문구(`--font-body`) + 버튼 2개(Secondary "취소" + Danger "삭제") 가로 배치, 모바일에서는 다이얼로그 폭을 화면 폭에 맞춰 축소.

### 6.9 안내 배너 / 빈 상태 / 로딩
- **안내 배너**: 참고 스크린샷 우측 상단의 옅은 안내 텍스트처럼, `--color-gray-500` + `--font-caption`으로 페이지 상단 우측에 배치(예: 공지, 저장됨 토스트).
- **`EmptyState`**: 아이콘(선택) + "등록된 할일이 없습니다" 같은 `--font-body` 안내 문구를 목록 영역 중앙에 배치.
- **`LoadingSpinner`**: `--color-primary` 단색 스피너, 별도 배경 오버레이 없이 콘텐츠 영역 중앙에 인라인 배치.
- **`ErrorMessage`**: `--color-danger-bg` 배경 + `--color-danger` 텍스트의 인라인 배너.

### 6.10 날짜 강조 규칙 (`DateRangePicker`)
- 요일 헤더: 일요일 `--color-sunday`, 토요일 `--color-saturday`, 평일 `--color-gray-900`.
- 오늘 날짜: `--color-primary-light` 배경 + `--color-primary` 텍스트로 강조.
- 선택된 시작일/종료일: `--color-primary` 배경 + 흰색 텍스트, 그 사이 범위는 `--color-primary-light` 배경.

## 7. 아이콘

- 라인 아이콘(채움형 아님), 기본 크기 20px, 목록/버튼 내부 아이콘은 16px.
- 색상은 본문 텍스트 색(`--color-gray-700`)을 기본으로 하고, 활성/강조 상태일 때만 `--color-primary`.
- 장식 목적의 아이콘 남용을 피하고, 액션이 명확한 곳(검색, 캘린더 선택, 삭제, 드롭다운 화살표)에만 사용한다.

## 8. 반응형 원칙

`8-wireframe.md` 10장의 반응형 규칙을 디자인 토큰 레벨에서 뒷받침한다.

- 768px 미만에서는 가로 배치 그룹(필터바, 시작일자/종료일자, 저장/취소/삭제 버튼)이 세로 스택으로 전환되고 폭 100%(`--space-4` 좌우 패딩만 남김)로 늘어난다.
- 버튼/입력창 높이는 모바일에서도 36px로 유지하되, 풀와이드 전환 시 터치 영역 확보를 위해 상하 패딩을 `--space-2`만큼 늘린다.
- GNB는 1024px 미만에서 햄버거 토글로 전환한다(`8-wireframe.md` 각 화면 모바일 절 참조).

## 9. 구현 매핑 요약

| 항목 | 위치 |
|---|---|
| 색상/타이포/간격 토큰 | `frontend/src/styles/globals.css`의 CSS 커스텀 프로퍼티 |
| 상태 배지 색상 매핑 | `frontend/src/features/todos/components/TodoStatusBadge.tsx` |
| 공용 컴포넌트 스타일 | `frontend/src/shared/components/{Button,Input,Modal,ConfirmDialog,LoadingSpinner,ErrorMessage,EmptyState}.tsx` |
| 반응형/GNB 전환 | `frontend/src/shared/layout/{AppLayout,ProtectedRoute}.tsx` |

이 문서의 토큰 값은 FE-1(프로젝트 초기 세팅) 착수 시 `globals.css` 초안에 그대로 반영하고, 이후 실제 구현 중 필요 시 값만 조정하며 이 문서를 함께 갱신한다.
